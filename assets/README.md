# Local reader assets

The reader uses local CSS, JavaScript, original SVG figures, and the MathJax TeX-to-SVG bundle. No CDN, analytics endpoint, external font, or remote typesetting service is needed to read the downloaded edition. Recording and reference links open external sources when selected.

`mathjax-tex-svg.js` identifies its upstream MathJax version as **3.2.2**. It was reused byte for byte from the retained earlier NPTEL Optimization edition rather than downloaded afresh for this project. The earlier edition did not retain an original download URL, so no specific CDN acquisition route is claimed. Upstream project: [MathJax](https://github.com/mathjax/MathJax). Its [Apache2.0 license](mathjax-LICENSE) is bundled here.

`math-config.js` configures the local renderer. `reader.css` and `reader.js` implement layout and reading controls; `lab.js` implements the two finite browser experiments explained in the numerical laboratory. Original figures in `figures/` are generated by the public Python figure generator. The chapter15 payoff atlas is generated by its chapter laboratory. The artifact manifest records the actual release-file digests.
