06. Portfolio risk depends on covariance; priced risk requires a model

Two securities each have a modeled expected return of 10% with return standard deviation 6%. Does putting half the capital in each reproduce the same risk? Only if their returns move together perfectly. With correlation 0.5, the portfolio has standard deviation about 5.20%, while its expected return stays 10%. This simple calculation changes the question from “How risky is this security?” to “How does it change the risk of the position I already hold?”

The lecture sequence develops that question into mean–variance portfolio selection and the capital asset pricing model, or CAPM. These are related but logically distinct. Covariance identities describe random returns. Optimization selects portfolios under stated objectives and constraints. CAPM adds assumptions about investors and market equilibrium to propose a relation for expected returns. Keeping these levels separate will prevent an index hedge from being mistaken for either a guaranteed investment return or the elimination of every source of risk.

1. Put the return horizon and portfolio weights in the equations 07:45

Consider a single common holding period. Let $R_i$ be security $i$'s simple total return, including distributions received over that period under the specified holding convention. Assume finite second moments. Write $\mu_i=E[R_i]$ and $\Sigma_{ij}=\operatorname{Cov}(R_i,R_j)$. Initial portfolio weights $w_i$ are fractions of initial net wealth and satisfy $\sum_i w_i=1$. Without intermediate rebalancing, the portfolio return is

$$R_P=\sum_i w_iR_i,\qquad \mu_P=w^\mathsf{T}\mu,\qquad \sigma_P^2=w^\mathsf{T}\Sigma w.$$

These weights are capital weights, not numbers of shares. A negative weight is a short position; weights above one require offsetting negative weights or borrowing. The algebra permits these positions, but actual borrowing, short-sale, and position constraints must be included in an investment problem. A dynamically rebalanced portfolio requires a cash-flow or return model that accounts for its trading dates.

To derive the variance formula, center each return and expand the square of $\sum_iw_i(R_i-\mu_i)$. Taking expectation produces every ordered pair $i,j$. Thus the two-security formula contains $2w_1w_2\Sigma_{12}$, since $\Sigma_{12}=\Sigma_{21}$. The covariance matrix is positive semidefinite because $a^\mathsf{T}\Sigma a$ is the variance of a real random variable for every vector $a$. A collection of individually plausible correlations can still fail this joint condition and cannot then represent a consistent return distribution.

For the opening equal-weight example,

$$\sigma_P^2=\tfrac14(0.06)^2+\tfrac14(0.06)^2 +2\tfrac14(0.5)(0.06)^2=0.0027.$$

Its square root is 0.0519615. Equal expected returns ensure the same portfolio expectation by linearity; lower variance comes from imperfect comovement. No CAPM assumption is needed for this result. Nor does it show that the securities are mispriced: it shows that standalone volatility cannot by itself describe their contribution to a diversified portfolio.

2. Find the minimum-variance portfolio before drawing the frontier 10:05

For two assets set $w_1=x$ and $w_2=1-x$. Define $v_1=\sigma_1^2$, $v_2=\sigma_2^2$, and $c=\Sigma_{12}$. Then

$$v(x)=x^2v_1+(1-x)^2v_2+2x(1-x)c.$$

The coefficient of $x^2$ is $d=v_1+v_2-2c=\operatorname{Var}(R_1-R_2)\ge0$. If $d>0$, differentiation and completion of the square give

$$x_{\rm GMV}=\frac{v_2-c}{d},\qquad v(x)=v(x_{\rm GMV})+d(x-x_{\rm GMV})^2.$$

GMV means global minimum variance among fully invested combinations allowed by this unconstrained scalar model. The nonnegative square proves globality. With a long-only constraint $0\le x\le1$, project this solution onto that interval. If $d=0$, the difference $R_1-R_2$ is constant almost surely, and the positive-curvature argument does not apply. Degenerate moment structures need direct analysis.

Use an original synthetic pair with $\mu_1=0.08$, $\mu_2=0.14$, $\sigma_1=0.10$, $\sigma_2=0.20$, and correlation 0.25. Then $c=0.005$, $d=0.04$, and $x_{\rm GMV}=0.875$. Its expected return is 0.0875 and variance is 0.009375, giving standard deviation approximately 0.096825. Investing 87.5% in the less volatile asset and 12.5% in the other has lower variance than either constituent. The higher-volatility security contributes diversification as well as its own uncertainty.

With unequal means, the identity $\mu_P=x\mu_1+(1-x)\mu_2$ lets us eliminate $x$ and express variance as a quadratic in the target mean. In mean–standard-deviation coordinates the nondegenerate unconstrained locus is a hyperbolic branch. The upper part above the GMV point is efficient: a point on the lower part is dominated by another feasible portfolio with the same variance and higher expectation. Constraints restrict the available portion. Equal means or perfect correlation can change the geometry, so the hyperbola and unique-composition language must not be applied without those qualifications.

For many assets, the corresponding mathematical problem is

$$\min_w w^\mathsf{T}\Sigma w\quad\text{subject to}\quad \mathbf1^\mathsf{T}w=1,\quad \mu^\mathsf{T}w=m_0.$$

Here $m_0$ is a prescribed expected return. Positive definite covariance makes variance strictly convex, and linear constraints define a convex feasible set. The frontier traces these minima as the target changes. Actual preference chooses a point on the efficient set; the covariance matrix alone does not determine a person's tolerance for risk. Mean–variance preferences are themselves a modeling choice, not a consequence of finite second moments. MIT's portfolio notes, slides 16–43, develop the covariance, frontier, and tangency interpretation.

The many-asset frontier has an explicit global certificate

The same completed-square idea extends to any number of assets. Suppose $\Sigma$ is positive definite and the mean vector $\mu$ is not a constant multiple of $\mathbf1$. Define

$$g=\Sigma^{-1}\mathbf1,\quad j=\Sigma^{-1}\mu,\quad A=\mathbf1^\mathsf{T}g,\quad B=\mathbf1^\mathsf{T}j,\quad C=\mu^\mathsf{T}j,\quad D=AC-B^2.$$

Cauchy–Schwarz for the positive-definite inner product $u^\mathsf{T}\Sigma^{-1}v$ gives $D>0$: equality would require $\mu$ proportional to $\mathbf1$. The two equality constraints can therefore be met by

$$w_*(m_0)=\frac{C-Bm_0}{D}g+ \frac{Am_0-B}{D}j.$$

Indeed, multiplying by $\mathbf1^\mathsf{T}$ gives one and multiplying by $\mu^\mathsf{T}$ gives $m_0$. Every other feasible portfolio is $w_*+h$, with $\mathbf1^\mathsf{T}h=\mu^\mathsf{T}h=0$. Since $\Sigma w_*$ is a linear combination of $\mathbf1$ and $\mu$, the cross term vanishes, leaving the exact identity

$$ (w_*+h)^\mathsf{T}\Sigma(w_*+h) =\frac{Am_0^2-2Bm_0+C}{D}+h^\mathsf{T}\Sigma h.$$

The final term is strictly positive for nonzero $h$. This proves existence, uniqueness, and global minimality for every target mean in the unrestricted-weight model, rather than relying only on stationarity. Completing the numerator gives $1/A+(A/D)(m_0-B/A)^2$; thus GMV mean is $B/A$ and GMV variance is $1/A$. Targets below that mean belong to the inefficient lower branch.

For a numerical certificate, take three mutually uncorrelated assets with variances $(0.01,0.04,0.09)$ and means $(0.04,0.08,0.12)$. At target mean 9%, the weights are approximately $(0.144231,0.461538,0.394231)$ and variance is $0.022716346$. Adding $h=(0.1,-0.2,0.1)$ preserves both constraints but adds variance exactly $0.0026$. The lab checks feasibility and this gap independently. With equal expected returns, only that common target is feasible and $D=0$; with a singular covariance, uniqueness can fail. A long-only problem can also have infeasible targets or binding boundaries. Those are different problems, not licenses to divide by a small surrogate for $D$.

3. A risk-free asset turns the efficient boundary into a line 25:03

Let $r_f$ denote a known simple return over the same horizon. This is a horizon return, not the continuously compounded annual rate $r$ used in carry formulas. Investing fraction $a$ in a risky portfolio $P$ and $1-a$ in the risk-free asset gives

$$E[R_C]=r_f+a(\mu_P-r_f),\qquad \sigma_C=|a|\sigma_P.$$

For $a\ge0$ and positive risk premium, the slope in mean–standard-deviation space is the Sharpe ratio $(\mu_P-r_f)/\sigma_P$. Increasing $a$ scales both the excess mean and standard deviation; it does not improve that slope. A negative cash weight when $a>1$ means borrowing. The straight-line opportunity set assumes borrowing and lending at the same rate, with no added constraints or costs.

The best positive slope among risky portfolios determines the tangency portfolio. A useful algebraic derivation avoids relying on a diagram. Let $b=\mu-r_f\mathbf1$, suppose $\Sigma$ is positive definite, and set $q=\Sigma^{-1}b$. Cauchy–Schwarz in covariance geometry implies

$$\frac{(w^\mathsf{T}b)^2}{w^\mathsf{T}\Sigma w} \le b^\mathsf{T}\Sigma^{-1}b,$$

with equality when $w$ is proportional to $q$. If $\mathbf1^\mathsf{T}q>0$, the normalized positive-premium tangency weights are $w_T=q/(\mathbf1^\mathsf{T}q)$. This is a special unconstrained result. A singular covariance, zero normalization, restrictions on short positions, or different borrowing and lending rates require an adjusted problem.

For the synthetic pair and $r_f=0.02$, $q$ is proportional to $(4.8,2.4)$, so tangency weights are $(2/3,1/3)$. Expected return is 10%, variance is $1/90\approx0.0111111$, standard deviation is about 10.5409%, and Sharpe ratio is about 0.758947. The GMV portfolio has lower volatility but a smaller excess-return slope. These are different optimality questions.

If all investors share these moment inputs, the available assets, and the same unconstrained mean–variance framework, their risk preferences can select different amounts of the same tangency portfolio. This separation result is conditional on the opportunity set and preferences. It is not a claim that every real investor should hold these synthetic weights.

4. CAPM adds market clearing to individual optimization 23:15

The lecture's equilibrium step assumes a single common horizon, homogeneous expectations, mean–variance portfolio choice, frictionless trading, and a common risk-free borrowing/lending opportunity, together with market clearing. In the familiar unconstrained formulation, investors may vary their risky allocation continuously. When they all hold the same proportions of risky securities, aggregate holdings force those proportions to equal the value-weighted market portfolio $M$ of the model's risky assets.

Why should covariance with $M$ determine an expected premium? Consider adding a small position in an asset's excess return to $M$, financed through cash. Write $X=R_M-r_f$ and $Y=R_i-r_f$. The perturbed excess payoff is $X+\epsilon Y$. Its Sharpe ratio is

$$H(\epsilon)=\frac{E[X]+\epsilon E[Y]} {\sqrt{\operatorname{Var}(X)+2\epsilon\operatorname{Cov}(X,Y) +\epsilon^2\operatorname{Var}(Y)}}.$$

At an interior maximum, neither a positive nor a negative infinitesimal trade improves the ratio. Differentiating at zero therefore gives

$$0=\frac{E[Y]}{\sigma_M} -\frac{E[X]\operatorname{Cov}(R_i,R_M)}{\sigma_M^3}.$$

For $\sigma_M^2>0$, define $\beta_i=\operatorname{Cov}(R_i,R_M)/\sigma_M^2$. Rearrangement produces the CAPM relation

$$\mu_i-r_f=\beta_i(\mu_M-r_f).$$

This is an expected-return restriction under equilibrium assumptions. The derivative argument needs interior feasible trades; binding constraints can replace an equality with inequalities or additional terms. CAPM does not follow merely from fitting a line through historical returns. Nor does it assert that each realized return equals its conditional or unconditional expectation. MIT's CAPM notes, slides 3–10 and 17–22, distinguish the model, beta estimation, and empirical assessment.

The capital market line relates expected return to total standard deviation for efficient cash–market combinations. The security market line relates expected return to beta for assets under CAPM. Substituting an arbitrary security's total volatility into the capital market line discards its residual risk and generally gives a different number.

5. Regression orthogonality is weaker than independence 12:00

For any finite-variance asset return with nonconstant market return, the population linear projection can be written

$$R_i-r_f=\alpha_i+\beta_i(R_M-r_f)+\varepsilon_i,$$

where $E[\varepsilon_i]=0$ and $\operatorname{Cov}(\varepsilon_i,R_M)=0$. The slope is the same covariance ratio; the intercept is $\alpha_i=\mu_i-r_f-\beta_i(\mu_M-r_f)$. These projection properties hold by construction. CAPM adds the restriction $\alpha_i=0$ for the true modeled market and expectations.

Taking variance yields

$$\sigma_i^2=\beta_i^2\sigma_M^2+\sigma_{\varepsilon_i}^2.$$

The terms add as variances, not standard deviations. The factor component's standard deviation is $|\beta_i|\sigma_M$; beta itself may be negative. Residual orthogonality removes the cross term, but does not establish independence, Gaussianity, unpredictability from other information, or absence of nonlinear dependence. A residual correlated with another omitted economic factor can be uncorrelated with this one market regressor. This precision matters when the lecture motivates residual randomness using market efficiency: a linear regression identity alone cannot prove informational efficiency.

In an original synthetic illustration let $r_f=3\%$, $\mu_M=12\%$, and $\sigma_M=4\%$. A beta-one portfolio with residual variance 0.002 has total variance $0.0016+0.002=0.0036$, or standard deviation 6%. Under CAPM its expected return is 12%. A beta-1.5 portfolio with zero residual has the same total standard deviation 6%, but expected return $3\%+1.5(9\%)=16.5\%$. A beta-one pure market position has standard deviation 4% and the original expected return 12%. These are model-based comparisons. Removing residual risk does not itself increase beta: increasing market exposure is a separate trade, often requiring leverage and funding.

6. What diversification actually needs 20:01

For $N$ equally weighted securities, let $\bar v_N$ be the average individual variance and $\bar c_N$ the average covariance over the $N(N-1)$ ordered distinct pairs. Counting terms in $w^\mathsf{T}\Sigma w$ gives exactly

$$\operatorname{Var}(R_P)=\frac{\bar v_N}{N} +\frac{N-1}{N}\bar c_N.$$

If average variances remain bounded and average covariance converges to $c_\infty$, the limit is $c_\infty$. A nonzero floor therefore needs nonvanishing average covariance; it is not a universal theorem that portfolio risk can never tend to zero. Independent returns with bounded variances have $\bar c_N=0$ and equally weighted variance tending to zero. Conversely, adding more highly correlated names need not substantially reduce risk. Even monotone reduction as each new security is added is not guaranteed for arbitrary changing sets of assets.

In a one-factor model with equal beta and mutually uncorrelated residuals of common variance $s_e^2$, the equal-weight variance becomes $\beta^2\sigma_M^2+s_e^2/N$. This is the familiar factor floor, now with its assumptions visible. Residuals being individually uncorrelated with the market is insufficient: correlated residuals can retain their own portfolio floor. Such a component may represent another common factor rather than diversifiable idiosyncratic risk.

Fully worked solutions

  1. Each variance is 0.0036 and covariance is $0.5(0.0036)=0.0018$. The portfolio variance is $0.25(0.0036)+0.25(0.0036)+0.5(0.0018)=0.0027$; its square root is 0.0519615. Expected return remains 10% by linearity. The result follows from moments alone. Pricing requires additional assumptions about preferences, other investment opportunities, and equilibrium, so the calculation does not establish mispricing.

  2. Expanding gives $v(x)=v_2+2x(c-v_2)+x^2d$ with $d=v_1+v_2-2c$. If $d>0$, setting $v'(x)=0$ gives $(v_2-c)/d$. Completing the square leaves $d(x-x_{\rm GMV})^2$, proving the unique global minimum. Here $d=0.04$ and $v_2-c=0.035$, hence $x=0.875$. Direct substitution gives variance 0.009375 and mean 0.0875. Since this weight lies in $[0,1]$, long-only constraints do not change it; an unconstrained solution outside the interval would be replaced by its closest endpoint.

  3. Cash has constant return, so its covariance with every return is zero. The risky fraction $a$ scales variance by $a^2$ and standard deviation by $|a|$; excess mean scales by $a$. For the pair, $b=(0.06,0.12)$ and $\Sigma$ has rows $(0.01,0.005)$ and $(0.005,0.04)$. Solving $\Sigma q=b$ gives $q=(4.8,2.4)$, whose normalization is $(2/3,1/3)$. Mean is 0.10; variance is $\frac49(0.01)+\frac19(0.04)+\frac49(0.005)=1/90$. Dividing excess mean 0.08 by its standard deviation gives approximately 0.758947.

  4. The denominator derivative at zero is $\operatorname{Cov}(X,Y)/\sigma_M$. The quotient derivative is therefore $E[Y]/\sigma_M-E[X]\operatorname{Cov}(X,Y)/\sigma_M^3$. An interior optimum sets it to zero. Multiplication by $\sigma_M$ gives $E[Y]=\beta_iE[X]$. Identifying that optimum as $M$ additionally uses common moment beliefs, a common investment opportunity set and horizon, mean–variance choice, frictionless unconstrained trading including cash financing, and market clearing. The projection formula for beta alone supplies none of this equilibrium identification.

  5. Center the projection equation. Squaring and taking expectation gives $\beta_i^2\sigma_M^2+\sigma_e^2+2\beta_i\operatorname{Cov}(R_M,e)$. Orthogonality kills the last term. Beta one with residual variance 0.002 has variance 0.0036 and standard deviation 6%, but CAPM expected return 12%. Beta 1.5 without residual has variance $2.25(0.0016)=0.0036$ and expected return 16.5%. Beta one without residual has variance 0.0016, standard deviation 4%, and expected return 12%. Merely deleting residual exposure keeps beta fixed; the higher-return comparison also increases systematic exposure.

  6. The diagonal sum contains $N\bar v_N$ terms in total, and the off-diagonal sum contains $N(N-1)\bar c_N$. Dividing both by $N^2$ yields the formula. Independent securities of common variance $s^2$ have portfolio variance $s^2/N\to0$. Alternatively, take $R_i=\mu_i+F+e_i$ with factor variance 0.01, residual variance 0.04, mutually uncorrelated residuals, and factor–residual orthogonality. Then distinct-security covariance is 0.01 and portfolio variance is $0.01+0.04/N\to0.01$. The positive floor comes from the specified common factor, not from the count of securities by itself.

"""Synthetic two-asset frontier, tangency, and diversification certificates."""

from math import isclose, isfinite, sqrt


def moments(x):
    return (
        x * 0.08 + (1 - x) * 0.14,
        x * x * 0.01 + (1 - x) ** 2 * 0.04 + 2 * x * (1 - x) * 0.005,
    )


def solve2(a, b, c, rhs):
    determinant = a * c - b * b
    if (
        not all(isfinite(v) for v in (a, b, c, *rhs)) or
        a <= 0 or
        determinant <= 0
    ):
        raise ValueError("Need a positive definite covariance matrix")
    return (
        (c * rhs[0] - b * rhs[1]) / determinant,
        (a * rhs[1] - b * rhs[0]) / determinant,
    )


def main():
    d = 0.01 + 0.04 - 2 * 0.005
    x = (0.04 - 0.005) / d
    mean, variance = moments(x)
    assert isclose(x, 0.875) and isclose(variance, 0.009375)
    for k in range(10001):
        z = -1 + k * 3 / 10000
        assert moments(z)[1] >= variance - 1e-14
        assert isclose(
            moments(z)[1] - variance, d * (z - x) ** 2, abs_tol=1e-14
        )
    try:
        solve2(-1, 0, -1, (1, 1))
    except ValueError:
        pass
    else:
        raise AssertionError("Negative definite matrix accepted")
    # Three assets: verify both constraints and the exact variance gap.
    mu, diagonal, target = (0.04, 0.08, 0.12), (0.01, 0.04, 0.09), 0.09
    g = [1 / v for v in diagonal]
    j = [m / v for m, v in zip(mu, diagonal)]
    aa, bb = sum(g), sum(j)
    cc = sum(m * z for m, z in zip(mu, j))
    determinant = aa * cc - bb * bb
    frontier = [
        ((cc - bb * target) * u + (aa * target - bb) * v) / determinant
        for u, v in zip(g, j)
    ]
    assert isclose(sum(frontier), 1)
    assert isclose(sum(w * m for w, m in zip(frontier, mu)), target)
    minimum = sum(v * w**2 for v, w in zip(diagonal, frontier))
    formula = (aa * target**2 - 2 * bb * target + cc) / determinant
    assert isclose(minimum, formula)
    direction = (0.1, -0.2, 0.1)
    assert isclose(sum(direction), 0, abs_tol=1e-15)
    assert isclose(sum(h * m for h, m in zip(direction, mu)), 0)
    perturbed = sum(
        v * (w + h)**2 for v, w, h in zip(diagonal, frontier, direction)
    )
    gap = sum(v * h**2 for v, h in zip(diagonal, direction))
    assert isclose(gap, 0.0026)
    assert isclose(perturbed - minimum, gap)
    print(f"Three-asset frontier weights={frontier}; variance={minimum:.9f}")
    q = solve2(0.01, 0.005, 0.04, (0.06, 0.12))
    weights = [v / sum(q) for v in q]
    assert isclose(weights[0], 2 / 3) and isclose(weights[1], 1 / 3)
    tm, tv = moments(weights[0])
    assert isclose(tm, 0.10) and isclose(tv, 1 / 90)
    sharpe = (tm - 0.02) / sqrt(tv)
    # Stationarity links each premium to its covariance with T.
    cov_t = [
        0.01 * weights[0] + 0.005 * weights[1],
        0.005 * weights[0] + 0.04 * weights[1],
    ]
    for premium, covariance in zip((0.06, 0.12), cov_t):
        assert isclose(premium, covariance * (tm - 0.02) / tv)
    assert isclose(0.25 * 0.06**2 * 2 + 0.5 * 0.5 * 0.06**2, 0.0027)
    assert isclose(0.04**2 + 0.002, 0.06**2)
    assert isclose((1.5 * 0.04) ** 2, 0.06**2)
    for count in (1, 10, 100, 1000):
        direct = (count * 0.05 + count * (count - 1) * 0.01) / count**2
        factor = 0.01 + 0.04 / count
        assert isclose(direct, factor)
        assert 0.04 / count < 0.05
    print(
        f"GMV weights=({x:.6f},{1-x:.6f}); mean={mean:.6f}; "
        f"sd={sqrt(variance):.6f}"
    )
    print(
        f"Tangency weights={weights}; mean={tm:.6f}; "
        f"sd={sqrt(tv):.6f}; Sharpe={sharpe:.6f}"
    )
    print(
        "Global quadratic certificate, tangency stationarity, CAPM variance "
        "and diversification checks passed."
    )


if __name__ == "__main__":
    main()
